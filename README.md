# Laboratorio VI - Programación II

Repositorio para el desarrollo de los ejercicios de diseño de API con
OpenAPI y su implementación con Java y Spring Boot.

## Estructura

- `LaboratorioVI/Ejercicio1`: diseño de la API de libros.
- `LaboratorioVI/Ejercicio2`: diseño de la API de cursos.
- `LaboratorioVI/Ejercicio3`: diseño de la API de reservas.
- `LaboratorioVI/Ejercicio4`: implementación de la API de libros.
- `LaboratorioVI/Ejercicio5`: implementación de la API de cursos.
- `LaboratorioVI/Ejercicio6`: implementación de la API de reservas.
